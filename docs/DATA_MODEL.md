# Data Model

## Table: consultations

| Column | Type | Description |
|---|---|---|
| id | STRING | Unique identifier (UUID) |
| input_text | TEXT | Raw consultation text sent by the clinician |
| soap_summary | TEXT | SOAP summary generated by the LangGraph agent |
| verification_ok | BOOLEAN | True if all 4 SOAP sections are present and complete |
| created_at | DATETIME | Creation timestamp (UTC) |

## Future Tables

| Table | Description |
|---|---|
| patients | Patient information (id, pseudonymized name) |
| consultations | Linked to patients via patient_id (US-06) |
| batch_jobs | Batch processing tracking (US-10) |

## Notes
- Patient data is never stored in plain text (GDPR compliance — US-05)
- Database is hosted on Supabase (managed PostgreSQL, EU region)
- All timestamps are stored in UTC
